# P1.5 视觉审查

复核 client/tests 下的六张交付截图。手机按原生 720×514 检查，平板按 1400×1000 检查。3 秒为截图走查判断，待计时试玩验证。

## 阻断

- **手机手牌正文未达到 12px 可读目标。** 720×514 图里「夜袭」浅色字墨迹约 10px，目标/路号与撤回按钮也偏小。截图可以测墨迹高度，无法据此确认 Godot 的字号属性。请在原生截图同时验卡名、状态、目标和主要操作，优先用更短的文案腾出空间。
- **哨探数值容易被当成实测。** 情报框写的是「侦知兵力：367 兵」，精确整数和确认口吻会造成误读。「疑似」或「估计」应和数值同一行、同等可见。若后端已有估计范围，直接展示范围。
- **逐队解释无法在 3 秒内读懂。** 回放中枪兵卡压住结算弹层标题。三行重复「无 · 无战术」，缺少「谁对谁造成了什么结果」的首行摘要。日报图仍为筹备态，上方结算提示横跨摘要，未提供已结算逐队样本。复验需覆盖至少一条战术生效和一条未生效，检查弹层层级以及原因是否能快速定位。

## 建议

- **四态目前无法一眼分清。** 四态图实际只显示「已出」和「今日不用」，撤回图另见可出牌样式；撤回成功靠顶部短提示确认。已出牌在金框与撤回按钮上最容易识别，待出和今日不用都偏暗。请补齐同屏四态样本，并让状态词或图形在去色后仍能区分。

## 通过

- **平板手牌条完整。** 两张 1400×1000 手牌截图中，手牌条约在 y=840–945，底边和按钮均可见。与 Dock 接缝接近，但当前截图未发生底部裁切。建议保持该截图作为回归基线。
