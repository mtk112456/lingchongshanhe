# 三种风格锁定稿

三稿采用同一构图规格。16:10 横屏，左侧约 70% 为五节点战局，右侧约 30% 为留白军令面板。宣纸、墨蓝、竹青、朱砂和深墨木色保持相同用途，文字由 Godot 渲染。

| 方向 | 视觉差别 | 选稿重点 |
|---|---|---|
| A 纸雕绘本 | 厚轮廓、宣纸叠层、暖色桌游质感 | 路线与纸层是否分明 |
| B 明亮 Q 版纸雕 | 同色板提亮，城标更圆、更简洁 | 小屏能否快速读出归属与可达路线 |
| C 手绘水彩纸雕 | 水彩晕染地貌，城标与面板保留清晰边缘 | 纹理是否干扰路线辨认 |

选稿后锁主视觉，再拆分 UI、城标与班宠资产。详见 [交接说明](HANDOFF.md)。
