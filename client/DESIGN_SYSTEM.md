# 《青竹文房·灵宠山河》客户端设计系统规范 (Design System v1.0)

> **版本**：v1.0 (5 节点切片完备版)  
> **制定**：Antigravity (Godot 前端主责)  
> **对齐基准**：`DETAIL_CHECKLIST.md`、`ART_BRIEF_GPT.md`、`ENVIRONMENT_SPEC.md`、`MAP_SPEC.md`  
> **设计哲学**：**Style C 水彩纸雕国风 + 轻 SLG 军事沙盘推演**（参考大厂结构与细节密度，不复制素材与文案）。

---

## 1. 设计基调与世界观

《青竹文房·灵宠山河》以中国传统文人书房案台为沙盘载体，融合宋代绢本山河画卷与纸雕微立体工艺：
- **画面质感**：宣纸底色微黄温润，工笔墨线勾勒关塞，水彩晕染五区山河；
- **沙盘层级**：全景沙盘地图铺底，UI 浮于绢帛之上，层级分明，透光微浮；
- **信息呈现**：文字全部由 Godot 引擎原生矢量渲染（思源宋体），底图与精灵图内**绝不烘焙任何文字/字母/数字**。

## 3. 字号标尺与排版层级 (Typography)

全游戏采用统一国风中文字体 `NotoSerifCJKsc-Regular.otf`，严格划分为 4 级字号标尺：

| 层级 | 字号 (px) | 适用场景 | 颜色搭配 |
|---|---|---|---|
| **L1 特大标题 / 印章** | `24–28px` (移动端) / `32–38px` (大屏) | 登录主标题、战报胜利/失败印章、结算大字 | `C_WOOD_DESK` / `C_ZHUSHA` / `GOLD_LIGHT` |
| **L2 一级标题 / 匾额** | `18–22px` | 页面大标题（HUD）、城名匾额、卡片首标题 | `C_WOOD_DESK` / `GOLD_LIGHT` |
| **L3 二级标题 / 按钮** | `14–16px` | 模块标头、主操作按钮文字、抽屉城池属性 | `#FFFFFF` (按钮) / `C_WOOD_DESK` (白底) |
| **L4 正文 / 状态文本** | `13–14px` | 战况描述、阵营特性、演武记录、输入框文本 | `C_WOOD_DESK` / `#554433` |
| **L5 辅助说明 / 标签** | `11–12px` | 归属印签、时间戳、战术提示、次级小按钮 | `#685848` / `C_MOLAN` / `NEUTRAL` |

> **红线规则**：手机最小正文不得小于 `12px`，保障小屏幕与 50% 缩放下依然清晰可读。

## 4. 间距体系与响应式布局 (Spacing & Grid)

### 4.1 8-Point 间距标尺
- **4px (Micro)**：图标与标签微距、微调内衬、双线包边间隙；
- **8px (Tight)**：紧凑按钮内边距、行内控件间距、列表项间隙；
- **12px (Regular)**：卡片标准 Padding、板块内元素分列间距；
- **16px (Medium)**：页面外边距 (Margin)、主卡片间距、侧栏安全留白；
- **24px (Large)**：弹窗/模态框内外边距、主要大板块分区留白；
- **32px+ (Section)**：全屏页面分段大间隔。

### 4.2 横屏-Only 目标分辨率断点
> **横屏锁定策略**：游戏全面采用横屏-Only 架构（`display/window/handheld/orientation=0`），不再维护手机竖屏。
1. **平板横屏标杆 (1400×1000)**：宽画卷全景沙盘，两翼悬浮印章图标与图例自然舒展，城池战术抽屉居中下沉 210px；
2. **手机横屏紧凑标杆 (720×514)**：极致紧凑小高度（唯一手机验收目标）：
   - 登录卡片自适应居中，字号与间距收敛，杜绝裁切；
   - 城池抽屉高度限定为 168px，动作栏自适应 34px 高度（横向拓宽保障触控面积）；
   - 底部 Dock 栏在抽屉滑出时顺畅下移让位，收起时贴底恢复；
   - 最低城池（松风渡 N1 / 雁回关 B_START）在小高度沙盘下标签安全避让，聚焦时不露白、不被抽屉遮挡。

## 5. 圆角、描边与纸雕阴影 (Borders & Shadows)

### 5.1 圆角标准
- **标准卡片/面板**：`corner_radius = 10–12px`（温润纸雕感）；
- **主功能按钮/输入框**：`corner_radius = 8px`；
- **次级胶囊/状态徽章**：`corner_radius = 4–6px`（印章方圆感）或 `corner_radius = height / 2`（全圆胶囊）。

### 5.2 纸雕双重描边
- **外框描边**：`width = 1.0–2.0px`，使用藤黄 `C_TENGHUANG` 或阵营专属色；
- **内框勾线**：内缩 3px 处绘制 `1.0px` 淡金/浅米色（`#DFCAA7`）辅助线，呈现传统线装书与雕版印刷的高级感。

### 5.3 暖灰漫反射阴影
- `shadow_color = Color(0.24, 0.20, 0.17, 0.35)`
- `shadow_size = 3–4px`
- `shadow_offset = Vector2(0, 2)`
- 严禁使用纯黑透明阴影，必须带暖木色漫反射，与宣纸底衬融为一体。

## 6. 核心组件 3 态与状态机规范

### 6.1 按钮组件 (Buttons)
所有可交互按钮必须具备完整的 **Normal / Hover(Pressed) / Disabled** 三态，且触控面积符合标准：

| 按钮类型 | Normal 状态 | Hover / Pressed 状态 | Disabled 状态 | 触控尺寸底线 |
|---|---|---|---|---|
| **Primary (朱砂)** | `C_ZHUSHA` 填充，金红微描边 | 压暗 15% `C_ZHUSHA.darkened(0.15)`，微下沉 1px | 灰褐 `#8A8074`，边框 `#6D6458`，字色灰 | 高度 ≥ 42px（紧凑横屏 ≥ 34px 且横向宽 ≥ 80px） |
| **Secondary (墨蓝)** | `C_MOLAN` 填充，深蓝描边 | 压暗 15% `C_MOLAN.darkened(0.15)` | 灰褐 `#8A8074` | 高度 ≥ 38px |
| **Confirm (竹青)** | `C_ZHUQING` 填充，青翠描边 | 压暗 15% `C_ZHUQING.darkened(0.15)` | 灰褐 `#8A8074` | 高度 ≥ 42px |
| **Ghost / Pill (胶囊)** | 宣纸色底 / 半透深木底 + 金边 | 亮金底色高光，字色加深 | 半透灰边 | 高度 ≥ 36px |

### 6.2 输入框组件 (LineEdit)
- **Normal 态**：宣纸白底 `#FFFEFB`，浅金褐边框 `1px`，占位文字 `#9E8D76`，字色 `C_WOOD_DESK`；
- **Focus 态**：宣纸白底，高亮烫金外边框 `2px` (`C_TENGHUANG`)，暖光环绕；
- **Disabled 态**：浅灰宣纸底 `#EAE3D5`，灰边框 `1px`，字色变淡。

### 6.3 选项卡与导航 (Tabs & Dock)
- **Normal 态**：透明宣纸底衬，次级文字灰褐 `#C4B295`；
- **Hover 态**：微亮深木色底，边缘微泛金色；
- **Active / Selected 态**：深墨木色底 `#3D2F24`，1px 烫金边框，文字为泥金高亮 `GOLD_LIGHT`。

### 6.4 状态徽章 (Badges & Seals)
- **阵营徽章**：按笔/墨/纸/砚阵营色填充，外勾 1px 白玉反光边，白字或金字；
- **战术据点徽章**：【大营】、【关隘】、【渡口】、【草庐】、【亭台】，国风印章样式；
- **尺寸**：高度 `20–24px`，左右 Padding `6–8px`，字体 `11–12px`。

## 7. 全局状态反馈与异常处理规范

| 状态 | 表现形式 | 规范实现 |
|---|---|---|
| **空态 (Empty)** | 宣纸画轴占位卡片 + 诗意文案 | 展示“云山苍苍，暂无烽烟军情”或“虚席以待，待君挥毫落子”，辅以山水微轮廓占位 |
| **加载态 (Loading)** | 墨韵流转指示器 | “墨韵推演中...” 伴随藤黄金色光晕周期脉冲，不阻塞前台浏览 |
| **错误态 (Error)** | 朱砂警示浮动 Toast | 悬浮顶栏下方，朱砂赤红边框 + 警示印章，停留 3.2s 缓动滑退 |
| **离线/断线态 (Offline)** | 顶部暗金警示条 | 网络中断时顶部即时拉出横幅：“山河烽烟微弱，正在重新联络学堂...”，提供【重试】动作，恢复后自动平滑收起 |

## 8. 动效时长与缓动曲线 (Motion & Easing)

严格遵循 `DETAIL_CHECKLIST.md` 规范，杜绝突兀闪现与线性生硬动效：

| 动效类型 | 目标时长 | 推荐缓动曲线 | 交互规范 |
|---|---|---|---|
| **微交互反馈** | `120–180ms` | `Tween.TRANS_QUAD`, `EASE_OUT` | 按钮按下缩放、Tab 焦点切换、高亮脉冲 |
| **浮层/抽屉展开** | `240–300ms` | `Tween.TRANS_CUBIC`, `EASE_OUT` | 城池战术抽屉升起、军令确认弹窗淡入 |
| **浮层/抽屉收起** | `180–220ms` | `Tween.TRANS_CUBIC`, `EASE_IN` | 抽屉快速下沉收起、Dock 栏快速贴底恢复 |
| **页面级转场** | `350–450ms` | `Tween.TRANS_CUBIC`, `EASE_OUT` | 沙盘切换至战报全屏、复盘回放淡入淡出 |
| **环境与沙盘呼吸** | `2.5–3.5s` 循环 | 正弦函数 `sin(pulse * speed)` | 旌旗迎风飘动、驰道金光流向、坚守金钟光环 |

> **红线规则**：所有动效均不得阻塞玩家点击与军令下达，测试用例和自动化流程可在静默态无缝执行。

## 9. 验收标准与合规底线

1. **50% 缩放可读性**：在 0.5x 缩放视野下，五城独立建筑轮廓、阵营色战旗、相邻驰道三层流光均清晰可辨，不被地形底色淹没；
2. **64px 轮廓可辨**：在低缩放（0.8x 及以下）与远景下，五城特征（西北关隘、东北关楼、中原草庐、西南竹亭、东南水渡）仍具清晰剪影；
3. **触控热区安全底线**：所有核心可点击元素触控热区严格满足 `≥ 44×44dp`（横屏紧凑按钮配置扩充水平垫片）；
4. **图中无字红线**：所有城名、战绩、诗词、属性均由 Godot TextServer 动态排版，底图与图元 PNG 严禁烘焙任何文字/字母/数字。
