## 结论（加/不加抽卡；主参考哪款；60–100 人是否可行）

1. **抽卡判断**：**坚决不加商业手游式概率抽卡（Gacha）！**
   - 面对 60–100 名真实中学生/小学生，概率抽卡必然催生“欧皇/非酋”心态、炫耀攀比与家长对“诱导赌博”的投诉。
   - 游戏内全面采用**“文玉直兑百宝阁 + 守城文脉解锁 + 赛季荣誉图鉴”**作为长期正向追求；原班级后台的 `shop_blind_box` 属于线下教师实体奖励，严禁直接搬进沙盘核心循环。
2. **主参考哪款**：确立**“双核驱动 + 文脉赋能”**路线：
   - **《率土之滨 / 三战》作为“战术骨架”**（0.35x/0.50x 低缩放秒读战局、半透明 HUD、贴底抽屉、阵营光环、高对比动态流光驰道）；
   - **《江南百景图》作为“视觉皮相”**（低饱和水墨纸雕、独立非均质建筑 Sprite、青绿山水生活小物）；
   - **《忘川风华录》作为“文脉灵魂”**（3:4 宣纸诗词卡面、名城名士图鉴、纯文化沉浸）。
3. **60–100 人是否可行**：**完全可行，但前端必须坚持“宏观军势聚合，微观下沉抽屉”**！
   - 地图上坚决不画任何个人的小人/小头像，全屏只画 4 色阵营归属大环与军势流动虚线；城池抽屉只显示“我方驻守 N 人 + 贡献 Top 3 英雄 + 我的状态”。

## 1. 参考与模仿边界

### 1.1 主参考选择与适配理由
- **为什么选《率土/三战》**：班级 SLG 必须有紧迫的战术博弈感。率土历经数千万用户验证的“Camera-First”半透明界面、贴底抽屉、阵营光环与连通线，能在 0.1 秒内告知学生“敌人在哪、能不能打”，这是纯经营类游戏无法提供的战术骨架。
- **为什么选《江南百景图》**：我们的美术全靠 GPT 生成。GPT 最稳定惊艳的风格是《江南百景图》式的工笔墨线水彩。草堂、水榭、峡谷关隘与古渡口，赋予了每个据点独一无二的人文地貌，杜绝换色页游感。
- **为什么选《忘川风华录》**：忘川的宣纸留白卡面、名士诗词排版与古风图鉴，最适合承载初中语文诗词与历史文脉，让学生占领城池后获得精神层面的成就感。

### 1.2 分模块模仿对应表

| 游戏模块 | 推荐主参考 | 具体落地标准（怎么模仿） |
|---|:---:|---|
| **地图城池 Sprite** | **《江南百景图》**<br>+ 程序化叠层 | 建筑本身为独立透明单体（512×512 RGBA），保留水彩青绿原貌，**严禁整城涂漆染色**。阵营归属通过 Godot 在地基绘制朱砂/墨蓝/藤黄/竹青光环，右上战台插战旗；长安王城尊享 136px 超大体量与双金环。 |
| **城池抽屉/城池卡** | **《率土 / 三战》**<br>极度克制版 | 贴底滑出紧凑抽屉（横屏高 168px/平板 210px）。首屏严格只呈现 4 要素：城名类型、驻防态、守备/战意差、【进军/驻守】大按钮；文脉小传收敛于右上角，0 秒决策。 |
| **易主动画/反馈** | **《率土之滨》**<br>+ 传统印章艺术 | 战报触发易主时，阵营玉玺大印从天而降（0.8 秒“轰”然盖落），旧旗卷起新旗展开，地表光环渐变，全过程 0.8~1.0 秒，干脆利落，杜绝全屏 3D 过场中断推演。 |
| **城望成长** | **《Unciv》精神**<br>+ 《百景图》细节 | **纯荣誉沉淀，0 数值膨胀。** 连续驻守 3 天亮起阵营风灯，7 天城名加盖“望城”金印，14 天全班解锁该城文脉大卡图鉴。城防生命始终锁定 3 点，不加攻击力，杜绝滚雪球。 |
| **文脉卡/图鉴** | **《忘川风华录》** | 3:4 竖版宣纸卡面：顶部高清城池立绘，中部名家书法诗句，底部地理小传与战役英雄学生榜（班级荣誉墙），支持学生一键分享。 |

### 1.3 不适用的参考及淘汰原因
- **淘汰《原神 / 崩坏：星穹铁道》的 3D 进城运镜**：它们依赖数万面的 3D 精模与无缝大世界摄像机；我们是 2D 静态工笔水彩画卷，生搬硬套 3D 进城只会变成抽搐的贴图位移拉伸，极具廉价山寨感。仅借用其高对比剪影与环境音效。
- **淘汰《文明 / Unciv》的 4X 地块改良与农田兵营微操**：学生课间只有 3~5 分钟，若每个城池还要修农田、管粮锤比，学生会认知过载，教师每天疲于解答操作咨询，产品根本无法常态化落地。
- **淘汰传统 SLG 的付费武将抽卡与战力压制**：坚守教育红线，全班必须战力均等。

### 1.4 “模仿”的红线边界
- **只借**：信息架构（三层视口）、细节密度（环境小物）、交互节奏（贴底抽屉、0.8s 盖印）；
- **坚决不借**：商业游戏美术原画、商业 UI 贴图、商业文案、数值滚雪球模型与概率抽卡机制。

## 2. 抽卡判断（明确结论、防赌博机制与替代方案）

### 2.1 明确结论：坚决不加商业化概率抽卡（Gacha）
- **核心理由**：班级是未成年人群体环境，概率抽卡（无论是否付费）都会直接引发班级内炫耀攀比、落后学生的挫败感，以及家长群对“学校软件引导抽卡赌博”的舆论风暴。在教育工具中引入抽卡是高危自杀行为。

### 2.2 现有系统 `shop_blind_box` 的处理
- 现有的 `shop_blind_box` 属于积分商城实物兑换（教师线下发放文具盲盒）。
- **裁定**：**不与游戏内沙盘玩法打通**。游戏内只保持“军令积分 → shop_orders → 兑换文玉”的合规通道，沙盘内绝不内嵌任何抽卡入口。

### 2.3 若用户强烈要求“随机惊喜”，UI 的防赌博去敏方案
若产品必须保留轻量随机乐趣，形式必须包装为**“晨读问策 / 每日求签”**，严密筑牢防线：
1. **命名去赌博化**：禁止出现“抽卡、卡池、单抽、十连、保底、SSR、金光”等一切商业手游黑话，统一称作“晨读求签”或“文房寻卷”；
2. **完全零氪免费**：每日提交军令或完成一次古诗文晨读，系统免费赠送 1 次求签机会，不能用真实货币或文玉购买次数；
3. **无阶级歧视的纯文脉掉落**：奖池内只有文房诗词挂件、成语卡、班宠趣味表情（如竹节开心/紧张，墨点傲娇），绝无“三阶战力差”的武将卡；
4. **UI 视听去博彩化**：严禁出现老虎机式轮盘、金光爆屏、彩虹闪烁等赌博暗示动效！UI 采用古雅的“摇竹筒抽出竹签”，展开一卷宣纸，缓缓浮现一句今日励志唐诗宋词，伴随一声清脆磬音，润物细无声；
5. **教师端最高权限**：教师后台具备一键关闭该模块的物理总开关，并可随时导出全班学生的寻卷历史明细。

### 2.4 推荐的无抽卡替代目标（长期追求力）
1. **文房百宝阁（明码标价直兑）**：学生通过胜仗战报与守城获得的文玉，在百宝阁直接兑换心仪的班宠新装束或行军流光皮肤（如白虎银刃、朱雀炽羽）；
2. **名城文脉图鉴收集**：参与某城攻防战累计 3 次即可解锁该城专属文脉图鉴，全赛季集齐 13 城图鉴可获得“山河大学士”班级荣誉铭牌；
3. **赛季终极荣耀**：赛季末获胜阵营全员在班级荣誉墙生成定制文房书签证书。

## 3. 城池设计（类型、状态、LOD、城望与 60–100 人卡面）

### 3.1 13 城一城一格规划
- **王城（1 座 · 长安）**：天下中枢，金色大雁塔 + 盛唐宫阙，专享 136px 超大体量与双金环；
- **大营（4 座 · 凉州/邺城/成都/建业）**：四阵营起点，长横截夯土关隘 / 铜雀台 / 杜甫草堂 / 夫子庙灯船；
- **关隘（3 座 · 汉中/襄阳/寿春）**：险要卡口，秦岭栈道绝壁 / 汉江锁钥城寨 / 八公山淮水古关；
- **渡口（2 座 · 江陵/松风渡原型）**：水网枢纽，屈原祠楚江轻帆 / 沿江柳岸乌篷码头；
- **文脉城（3 座 · 洛阳/太原/长沙）**：文化重镇，龙门石窟牡丹 / 晋祠双塔古柏 / 岳麓书院橘子洲头。

### 3.2 城池状态与视觉表达
- **中立态**：建筑保持原色，灰色石质台基，插暗灰三角旗，无地表光环；
- **阵营态**：建筑原色不变，地基浮现对应阵营色光环（朱砂 `#b83b32` / 墨蓝 `#1e3a5f` / 藤黄 `#cf8325` / 竹青 `#276f57`），右上战台插阵营战旗，城名签描对应阵营色边框；
- **选中态**：金色脉冲呼吸光环，相连拓扑驰道激活三层流光；
- **易动态**：对应阵营玉玺大印从天而降（0.8 秒落印），战旗翻卷换色，升起微茫硝烟。

### 3.3 4 级 LOD 分级标尺
- **LOD 0 (<0.45x，如 0.35x 平板全景)**：**彻底收敛文字，只看大局！** 仅显示城池 Sprite 剪影 + 阵营光环（半径放大至 32px） + 战旗 + 16 条拓扑驰道，**隐藏所有城名与归属纸签**，防止 26 块铭牌相互踩踏遮挡；
- **LOD 1 (0.45x–0.75x，如 0.50x 手机横屏)**：精简单行宣纸城名签（62×20px），隐藏归属副签；
- **LOD 2 (0.75x–1.30x，常规战术近景)**：完整双层纸签（主签城名 + 归属副签 + 守备盾徽）；
- **LOD 3 (>=1.30x，文脉特写)**：激活文化地标黑金标签（如【都】伊洛文脉）与名篇小传。

### 3.4 城望成长体系（0 数值膨胀）
- **守备 3 天**：城头点亮阵营色风灯微光（外观细节微变）；
- **守备 7 天**：城名签旁加盖烫金“望城”御印，军令下达时触发专属号角战鼓音效；
- **守备 14 天**：全班解锁该城高清仿古立绘文脉大卡，收录入班级数字荣誉馆；
- **城防生命固定为 3 点**，不加攻击力，不加速资源产生，只沉淀情感与荣誉。

### 3.5 60–100 人城池抽屉排布方案（杜绝糊屏）
在 720×514 手机端极限紧凑空间下（抽屉高 168px），**严禁在抽屉内平铺 100 个学生头像！** 采用“数据聚合 + Top 3 英雄榜”架构：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 【汉中】[秦岭栈道关隘]  归属：笔阵营                                  [传][文] [✕] │
├────────────────────────────────────────────────────────────────────────┤
│ 🛡️ 城防守备：3 / 3 点       │ 👥 战力聚合：我方 18人 vs 敌方 6人 (战意差 +12)       │
│ 连通驰道：凉州、襄阳、长安   │ 🏅 前三先锋：青竹一(8令) · 青竹五(5令) · 青竹八(3令)   │
│ 战术地位：西出秦川，直取中原 │ 📍 我的令旗：未下达 / 已驻守该城                      │
├────────────────────────────────────────────────────────────────────────┤
│     [⚔️ 进军攻打]         [🛡️ 驻守据点]         [🔍 斥候]      [↩️ 撤销]     │
└────────────────────────────────────────────────────────────────────────┘
```
- **核心原则**：
  1. 仅显示“驻守总人数”与“战意差”宏观大数；
  2. 仅列出贡献前 3 名的先锋学子名字；
  3. 醒目标识“我当前的军令状态”；
  4. 绝不在首屏平铺长篇小传，文脉统一收入右上角【传】/【文】图标。

## 4. 60–100 人方案（玩法公平、抗糊屏与教师免维护）

### 4.1 玩法与公平性
- **阵营划分**：**必须采用 4 阵营 × 15–25 人，坚决不采用 2 阵营！**
  - 2 阵营在班级内极易变成“强推推平”，一方有几个活跃学霸就能碾压全场，落后方迅速弃玩；
  - 4 阵营（笔墨纸砚）形成天然的“合纵连横”三角平衡，弱势阵营可联手制衡领头羊，容错率最高。
- **未活跃学生兜底**：缺令学生系统自动判定为“本阵营大营待命”，自动结算 60% 基础后勤分，避免班级内因战力差距产生对落后学生的指责与霸凌。
- **班级与年级边界**：一个 Game 实例严格对应一个班级（单班 40–50 人，或合班 60–80 人）；教师通过后台统一查看各班对局。

### 4.2 前端抗糊屏策略（核心工程主张）
- **0.35x / 0.50x 沙盘绝不显示任何个人标记**：
  - 100 个学生如果都在地图上插旗，沙盘会沦为灾难级的“麻子脸”；
  - 沙盘上只绘制：① 城池据点的大环；② 驰道上的行军流向粒子（以流光厚度和粒子流速体现“18 人大军”还是“2 人轻骑”）；③ 城池旁一个极小的轻质军符徽章（如 `🛡️ 18`）；
  - **沙盘永远保持宋画的空灵大气，个人数据彻底下沉至抽屉与战报**。

### 4.3 教师运营（真正做到“无需每天干预”）
- **全自动日程**：每日 21:00 系统后台 Cron 自动锁令与原子结算（已在切片中全绿通过），次日早自习战报自动生成，教师日常 0 操作；
- **控制台极简集成**：教师面板只保留 3 个紧急操作：【一键锁令/结算】、【全班战报一键投屏】、【期末文脉积分导出】。

## 6. 风险与不同意 OpenCode 的地方

1. **不同意在沙盘上渲染个人行军小人或散碎旗帜**：
   - 即使后端算力充裕，前端屏幕像素也是极其有限的。在 720×514 手机端，必须坚守“沙盘只看阵营军势，个人下沉抽屉”的铁律，绝不允许破坏水墨卷轴的纯净感。
2. **不同意过早引入抽卡与商城系统的后端复杂度**：
   - 当前第一优先级是验证 8–12 真实学生的玩法闭环，第二优先级是 4 城垂直切片与 100 人聚合结算。过早投入抽卡架构会分散精力，且增加数据库状态回滚的脆弱性。
3. **坚持横屏-Only 架构，不再回退维护手机竖屏**：
