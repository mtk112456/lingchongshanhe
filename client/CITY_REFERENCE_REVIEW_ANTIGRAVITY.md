> **核心命题**：**《青竹文房·灵宠山河》城池设计主要模仿哪款游戏？**  
> **评审视角**：Google Antigravity（Godot 前端、设计系统、信息层级、交互与多端适配主责）  
> **项目硬约束**：班级级轻 SLG（8~40 人学生）、13 城沙盘、横屏-Only（手机 720×514 / 平板 1400×1000）、无人工美术（GPT 资产 + 程序化合成）、纯教育文脉属性。

## 1. 核心结论：主参考哪款？为什么？

### 结论：坚决拒绝单一模仿，确立“双核驱动 + 文脉赋能”的黄金三角路线

**主参考：《率土之滨 / 三战》（战术骨架） + 《江南百景图》（视觉皮相） + 《忘川风华录》（文脉灵魂）**。

```text
       ┌────────────────────────┐
       │   视觉皮相：江南百景图   │  ← 2D 水墨水彩、低饱和纸雕、非均质建筑、生活小物
       └───────────┬────────────┘
                   │
       ┌───────────┴────────────┐
       │   战术骨架：率土 / 三战  │  ← 50% 缩放可读、贴底抽屉、归属光环、三层流光驰道
       └───────────┬────────────┘
                   │
       ┌───────────┴────────────┐
       │   文脉灵魂：忘川风华录   │  ← 诗词名篇、名城小传、班级名誉图鉴、无氪纯文人
       └────────────────────────┘
```

### 为什么这个组合最适合我们？
1. **为什么《率土之滨 / 三战》是不可替代的“骨架”**：
   - 我们的内核是策略对抗。率土/三战被数千万玩家验证的核心是：**“50% 甚至更低缩放下，1 秒钟就能看清城是谁的、周围连着哪条路、城防剩几点、我能不能下令打”**。
   - 很多国风游戏把城池做成繁复的插画，远看一团黑糊，完全失去战术价值。我们必须借用率土的半透明 Camera-First HUD、贴底战术抽屉、阵营光环和高对比动态流光驰道，保障决策干脆利索。
2. **为什么《江南百景图》是最佳的“皮相”**：
   - 我们没有 3D 引擎和大规模人工美术，资产由 GPT 生成。GPT 最稳定、惊艳的风格正是《江南百景图》式的工笔墨线白描结合水彩晕染；
   - 草堂、水榭、断崖关隘、曲水兰亭天然具备中国古典人居的温度，能把冷冰冰的“据点 A/B/C”变成有山水灵性的江南与中原名胜。
3. **为什么《忘川风华录》是点睛的“灵魂”**：
   - 我们是教育文脉游戏。学生攻打一座城，不只是为了拿积分，而是为了解锁杜甫草堂的《茅屋为秋风所破歌》、兰亭的曲水流觞、赤壁的豪迈。
   - 忘川风华录的卡面大面积宣纸留白、竖版排印书卷气、名士与名城羁绊，正是洗脱页游土味、实现教育文化沉浸的标杆。

## 3. 哪些参考不适合我们？为什么？

### 1. 坚决排除：《原神 / 崩坏：星穹铁道》的 3D 开放世界表现
- **为什么不学**：
  - 它们依靠的是百人美术团队堆出来的 3D 实时渲染、动态昼夜天气系统、成千上万个面数的高模，以及镜头无缝推入城门的第一人称漫游；
  - 我们的技术基石是 2D Godot + GPT 生成的 2D 静态工笔水彩画卷。如果在 2D 贴图上生搬硬套原神的“进城镜头运镜”，只会做出抽搐滑稽的伪 3D 位移拉伸，极具山寨廉价感；
  - **唯一可借鉴且已经落地的**：仅限高对比地标剪影、环境音（风声、水声、雨声）与界面转场的节奏感，其余 3D 镜头与开放世界体系一律封杀。

### 2. 坚决排除：《文明 / Unciv》的 4X 重度城建与六角地块微操
- **为什么不学**：
  - Unciv/文明是硬核 4X 游戏：圈地造农田、伐木修路、人口与粮锤比平衡、科研树升级、生产力调度；
  - 我们服务的是**真实班级学生（8~40 人）**，学生每天下令仅限课间或早晚自习的 3~5 分钟。如果每个城池还要造兵营、管内政，不仅学生认知过载崩溃，教师每天也要疲于解答操作咨询，产品根本无法常态化运转；
  - 必须保持“城池即要塞节点，下令即战略行军”的极简轻量。

### 3. 坚决排除：传统商业 SLG（万国觉醒、三国志·战略版）的付费养成与滚服生态
- **为什么不学**：
  - 氪金抽武将、付费加速城建、行军疲劳度卡死、战力数值碾压，这些商业套路与学校班级教育场景彻底冲突；
  - 所有学子必须处于完全平等的战力基线，拼的是全班集体的决策与文脉答题积累。

## 4. 最优先 3 个城池设计决策（按优先级排序）

### 决策 1（P0）：城池 Sprite 采用“纯净中立建筑 + 引擎程序化叠层”，严禁烘焙死阵营态
- **具体要求**：
  - GPT 交付的 13 座城池资产必须全部是透明底的单体建筑 PNG（512×512 RGBA），**图内绝对禁止带任何阵营颜色、文字、底座或阴影**；
  - 4 种阵营色地基环、战台旗帜、纸签铭牌、选中呼吸金圈全由 Godot 代码在沙盘世界坐标系中动态装配；
- **工程收益**：
  - 13 张原始图即可程序化演化出 52 种阵营态，彻底消除美术重复工作量，且易主换旗、光环渐变毫秒级丝滑过渡。

### 决策 2（P0）：城池抽屉坚守“首屏战术极简，文脉二级下沉”铁律
- **具体要求**：
  - 在横屏（尤其 720×514 手机端）下，抽屉高度严格锁死在 168px 以内，绝不遮挡上方选中的城池本体；
  - **首屏严禁平铺长篇城池介绍**，必须在 0.1 秒内给清：【守备】、【驻防】、【战意差】、【进军/驻守按钮】；
  - 城池小传与诗句收纳进抽屉右上角【传】/【文】二级入口，点击后以半屏书卷式浮层滑出，战术决策与文化鉴赏各安其位。

### 决策 3（P1）：城望系统定位为“纯外观荣誉与文脉记忆”，严守 0 数值膨胀红线
- **具体要求**：
  - 坚守 3 天亮灯笼、7 天加盖“名城”印签、14 天全班解锁文脉图鉴大卡；
  - 守城不加城防生命、不加攻防系数、不产生资源滚雪球；
  - 让“守城”成为全班共同守护一段历史记忆的荣誉，杜绝弱势阵营因数值劣势被彻底打崩。

## 5. 对 `CITY_DESIGN.md` 的同意与不同意（直言直陈）

### 【完全赞同的 4 点】
1. **完全赞同“13 城一城一格，每城有明确类型与独特地标”**：
   - 将 13 城细分为王城、大营、关隘、渡口、文脉城、田园城，彻底击碎了传统换色页游的审美疲劳。成都草堂、太原双塔、建业灯船、汉中栈道辨识度极高。
2. **完全赞同“城池 Sprite 512×512 透明底，不烘焙文字与阵营色”**：
   - 完全契合 Antigravity 制定并跑通的设计系统规范，保障了组件化装配与轻量化体积。
3. **完全赞同“王城长安处于四区主干道交汇中心，专享 136px 超大尺寸与双金环”**：
   - 这与我们在 `MAP12_REVIEW_ANTIGRAVITY.md` 提出的“中心设立第 13 终极要塞”的独立推演完全契合，且在原型验证中效果极其出众。
4. **完全赞同“不做建筑升级树，不做微操，不做付费加速”**：
   - 牢牢守住了轻量教育 SLG 的红线。

### 【明确反对与需要修正的 3 点分歧】

#### 分歧 1：反对在城池抽屉首屏平铺城池小传
- **原案表述**：`CITY_DESIGN.md` 第 6 节把“城池小传、文脉卡、城史”作为抽屉内容展开。
- **Antigravity 修正意见**：在手机横屏 720×514 下，抽屉内边距只有几像素。如果城池小传直接在抽屉里占位，即使只放两行字，主操作按钮也会被强行挤出屏幕底边！**必须把小传和文脉从抽屉正文中彻底抽离，统一收敛至抽屉右上角【传】/【文】图标**，点击后弹独立纸卷弹窗，抽屉首屏必须 100% 服务于军令下达。

#### 分歧 2：对“连续控制 7 天守备 +0（不加数值）”的表述提出质疑
- **原案表述**：第 7 节写道“守备 +0（不加数值）”。
- **Antigravity 修正意见**：既然不加数值，在界面上写“+0”会让学生大惑不解，甚至以为是系统 Bug。建议去掉“+0”字样，直接设计为**荣誉视觉强化**——城名签上方加盖金色“望城”御印，且学生点击驻守时触发专属战鼓振奋音效。荣誉仪式感远胜于冷冰冰的“+0”。

#### 分歧 3：原案漏掉了“城池易主后的大保护期与交互锁定”
- **原案漏洞**：第 8 节只提到了易主动画，未定义防偷袭保护机制。如果上午易主，下午被敌方单人立刻偷袭反夺，学生会产生严重的挫败感。
- **Antigravity 补充方案**：在易主动画播放完毕后，沙盘上的该城池应进入**“固防休整期”**（地基周围环绕半透明青竹栅栏光晕，持续至当日夜间结算），提示“据点重组休整中，防线已稳固”，增强阵营守土的阶段性安全感。
