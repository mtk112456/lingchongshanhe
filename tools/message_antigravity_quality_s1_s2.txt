【S1/S2 冲刺：把“能玩”做成“看得爽、学得会”】

先读：

```text
QUALITY_BENCHMARK.md
```

目标不是加内容，是补**反馈、动效、教学、音频**。

---

## S1 看得爽（优先）

### 1. 战斗回放

现在：

```text
单位站桩、伤害靠文字、城墙数字变化
```

要改成：

```text
冲锋：单位向前 12–18px，80ms 回弹
受击：闪白 60ms + 轻微后仰
飘字：伤害数字上浮 24px，300ms 淡出
箭矢：弓兵攻击时飞一支箭，120ms 到达
破墙：城墙抖动 + 碎石粒子 + 重震
死亡：淡出 + 倒下
胜负：破城/守住印章落下
```

音效钩子先留：

```gdscript
AudioManager.play_sfx("hit")
AudioManager.play_sfx("wall_break")
```

资源由 OpenCode 接入，你只调用。

### 2. 手牌

```text
抽牌：从牌堆位置翻入
重抽：4 张一起飞出再翻入
出牌：卡面抬起 → 飞向城池 → 落位
撤回：飞回手牌
不可用：轻抖 + 灰
```

### 3. 转场

```text
登录 → 地图：淡入 + 轻微缩放
地图 → 抽屉：220ms 滑入
地图 → 战报/回放：淡入
所有页面：禁止硬切
```

### 4. 设置页

```text
音量：总/音乐/音效
减少动效：开/关
服务器地址
版本号 + 退出登录
```

## S2 一学就会

```text
首次登录 3 步教学：
  1. 点一座城
  2. 选一张牌
  3. 确认出令
可跳过，完成标记存 user://
```

术语统一：

```text
队 / 路 / 前 / 后
```

错误提示人话：

```text
CHANGAN_LOCKED → 长安第 3 周才开放
SEASON_FINAL_WEEK → 最后一周只能打长安或邻城
SCOUT_REQUIRED → 先出哨探
```

## 验收

```text
720×514 与 1400×1000 60fps
任何按钮 ≥44×44
任何操作 100ms 内有反馈
首次玩家 60 秒内独立出令
录 60 秒屏：关声音能看懂，开声音不刺耳
四个客户端套件全过
```

不改 server / schema / API。
