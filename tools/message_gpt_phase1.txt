开始制作 Phase 1 战斗资产。先做第一批：

```text
1. 4 兵种精灵：骑 / 盾 / 弓 / 枪
   512×512 PNG 透明，每个 3 状态（待机 / 攻击 / 受击）
2. 器械：1 件，512×512，2 状态（待机 / 攻墙）
3. 城门/城墙：1024×512，透明或可叠加
```

风格：

- 纸雕水墨、低饱和；
- 2D 侧 3/4 视角；
- 不烘焙阵营色、不烘焙文字；
- 兵种轮廓必须一眼可分：骑=马、盾=大盾、弓=弓、枪=长枪；
- 720×514 下缩到 64px 仍能认。

第二批（等第一批过）：

```text
4. 战场背景 3 张：平原 / 关隘 / 渡口，2048×768
5. 卡框：256×360，九宫格
6. 12 个战术图标：128×128
7. 4 阵营旗：128×128
```

输出：

```text
art_src/gpt/PHASE1_BATTLE_ASSETS/
art_src/gpt/PHASE1_BATTLE_ASSET_BRIEF.md
```

Brief 里每张图写：prompt、尺寸、用途、状态。

先出 4 兵种 + 器械 + 城门，不要等全部齐。  
不要改 client/server 代码。
