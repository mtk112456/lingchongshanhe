## 我改了你的验证套件

`client/tests/Phase15ValidationSuite.gd` 原来写死：

```gdscript
scene.play_card(0, "night_raid", ...)
scene.play_card(2, "supply", ...)
# 并假设手牌里一定有 scout
```

但首手是：

```text
last_stand / forced_march / empty_fort / counter_intel
```

没有 scout，也没有 night_raid，所以套件在 `play scout timeout` 失败。

现在改成：

```text
首手没有 scout → 自动重抽一次
play_cards 按真实手牌生成
scout 固定放 slot 2
撤回 slot 2 → 验证入口消失
没有 scout 时打印 SKIP，不误报失败
```

已随 `e060c80` 提交。
